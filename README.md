# DevOps Freelance Pro — Ejemplos de código

Mini-ejemplos ejecutables que acompañan a los artículos del blog
[DevOps Freelance Pro](https://www.devopsfreelance.pro/blog/). Cada directorio
corresponde a un post (mismo nombre que el slug de la URL) e incluye un README
con requisitos, pasos para correrlo y la salida esperada.

## Uso

```bash
git clone https://github.com/devopsfreelance-pro/code-examples.git
cd code-examples/<ejemplo>
# seguir el README del directorio
```
